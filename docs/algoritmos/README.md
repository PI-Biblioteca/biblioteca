# Algoritmos

Documentação da modelagem algorítmica, pseudocódigos e estruturas de programação do Sistema de Gestão de Biblioteca.

## Tópicos

1. [Modelagem de Algoritmos](./algoritmos.md) — índice e organização geral.
2. [Algoritmos de Cadastro](./cadastros.md) — cadastro de autores e livros.
3. [Usuário e Disponibilidade](./usuarios-disponibilidade.md) — cadastro de usuários e consulta de livros disponíveis.
4. [Empréstimos](./emprestimos.md) — registro de empréstimos e devoluções.
5. [Histórico de Empréstimos](./historico.md) — consulta dos empréstimos registrados.
6. [Modularização e Fluxo](./apoio-e-fluxo.md) — funções de apoio, fluxo geral, estruturas de programação e relação com RF01–RF07.

## Organização

A documentação foi dividida por funcionalidade para manter os arquivos menores e facilitar a implementação individual e a integração posterior dos algoritmos.
